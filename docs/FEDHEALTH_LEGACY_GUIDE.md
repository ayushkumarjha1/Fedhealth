
1. **The Conflict**: Hospital A has rare oncology data. Hospital B has diverse pathology data. Combining them could save lives. But privacy regulations make centralizing data impossible and illegal.
2. **The Complication**: Standard Federated Learning (FedAvg) fails in healthcare because hospital data is inherently non-IID (demographics, equipment, protocols). Local models drift apart and diverge.
3. **The Solution**: FedHealth provides an extensible algorithm zoo (FedProx, SCAFFOLD, FedNova) to conquer statistical heterogeneity while enforcing strict DP-SGD privacy.
4. **The Resolution**: By combining empirical attack defense (MIA) with physiologically grounded Explainable AI (Cohort-Centroid IG), FedHealth bridges the gap between deep learning theory and real-world clinical trust.
